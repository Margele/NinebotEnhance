# 预览旋转与手机输入法

本地和巡航预览共用一条文字按钮工具栏（`PreviewToolbar`）：返回、横屏、输入法、深色 / 浅色、校准（触摸屏在线时才出现），最后一个按钮本地预览是“关闭”（只收起窗口，什么都不结束），巡航预览是“结束”（停止投屏）。窄窗口将标题和按钮分成两行。本地预览的“横屏”向宿主 Activity 申请横屏（`setRequestedOrientation(SCREEN_ORIENTATION_USER_LANDSCAPE)`），整个窗口连同工具栏转过来，画面按新尺寸重新适配；“还原”或收起预览时把 Activity 原来的方向还回去，选择在同一虚拟显示器会话内保留。九号的 MainActivity 在 configChanges 里声明了 orientation，不会因此重建；宿主被重建时预览按原有逻辑在重建后的 Activity 上重开，方向值在 ActivityRecord 里保留。巡航预览嵌在九号页面里，它的“横屏”只将预览画面顺时针转 90° 并同步转换触控坐标，不改九号 Activity 的方向。两者都不改虚拟屏应用配置或仪表帧；切换和尺寸变化取消旧拖动。

先点副屏应用输入框，再点“输入法”，使用手机当前键盘输入。中文候选词在手机组词，确认后提交；支持退格、前向删除和回车。“收起”关闭键盘，暂停/退出预览会关闭输入连接。键盘弹出后预览避开其区域，触控按新尺寸映射。

`PreviewPicture` 提供标准 InputConnection，不安装或切换输入法，也不读取其他应用的 InputConnection。输入使用通用文本类型，无法获知副屏原输入框的密码/数字类型、周围文字或搜索动作；没有图片或附件转发。确认后的文字和编辑键发送给副屏当前焦点，特殊自绘输入框的支持取决于应用。

可由 Android 虚拟键盘映射的短文本直接注入按键。中文、emoji 和较长文本使用临时标为敏感内容的剪贴板条目，再向本次副屏发送粘贴键。约 1.2 秒后或正常停止时，仅当剪贴板仍是本模块的同一条内容才恢复此前条目；期间用户复制新内容时不覆盖它。剪贴板历史及进程被强杀时的恢复无法保证。原剪贴板含文件 URI / Intent 时拒绝此路径，避免丢失无法重新授权的内容；不支持粘贴的自绘输入框可能无法接收 Unicode。诊断不记录输入文字或剪贴板内容。

创建时将本次副屏的 IME 策略设为 `DISPLAY_IME_POLICY_HIDE`，避免键盘同时出现在副屏；结束时还原原策略。手机键盘由预览按钮显式请求，不改全局默认输入法、主屏方向或应用作用域。文字操作经过原 UID/会话检查，Root 再核对本次正数 displayId 和 uniqueId。单次提交最多 2048 UTF-16 单元，删除最多 128 次；公共编辑按键接口拒绝 Home、电源、应用切换等系统键。

主机断言覆盖旋转后四角 / 中心、预览被键盘压缩及顶部额外加色边后完整应用区域的坐标往返，以及 Unicode 编码、提交 / 删除长度和编辑键边界。自定义颜色不改变几何换算。Android UI、IME 组词、剪贴板权限与实际粘贴行为需要在设备验证。

本地 Dialog 与仪表 Activity 的系统栏由 `PreviewSystemBars` 管理。`ThemeMode` 先检查宿主夜间配置，再参考可见容器的中性实色背景；不让首个灰色文本覆盖夜间模式，也不从模块自己的预览层反推宿主主题。窗口获得焦点、恢复显示及配置变化后刷新预览背景、工具栏和系统栏图标。

Android 15+ 面向新 SDK 的状态栏背景颜色 setter 不再改变实际背景，参见 [Window.setStatusBarColor](https://developer.android.com/reference/android/view/Window#setStatusBarColor(int))。新实现把不接收输入的 View 加入 DecorView overlay，按 `statusBars` / `navigationBars` 的实际 Insets 绘制背景；不绘制 IME 高度、不添加重复内容边距，也不进入投屏像素。深色背景清除两个 LIGHT appearance 标志，图标及手势指示条为浅色；浅色背景设置对应标志。预览层禁止系统再次 Force Dark，避免重复变色。配色和 Insets 策略参考 [Android 系统栏布局指南](https://developer.android.com/develop/ui/views/layout/edge-to-edge-manually)。

本地窗口继续使用自己的边到边布局；仪表窗口保持原布局方式，仅借用系统栏属性。关闭时移除背景层、配置 / 焦点监听和待处理回调，恢复原颜色、对比保护、窗口标志及图标明暗。诊断记录 `PREVIEW BARS` 的暗色判断、背景色与栏高度。键盘可通过自己的窗口控制导航区域，不能用应用侧单元测试证明 ColorOS / 输入法最终绘制；两个预览入口均需设备验收。

验收：两个预览入口均检查工具栏、旋转后四角触控、拖动中切换、折叠重建；高德搜索框中验证中文确认、英文、emoji、退格、回车、收起和停止后的旧输入回调；确认旧剪贴板恢复、期间手动复制的新内容保留，同时检查副屏方向和息屏保持。查看 `ROOT IME` 策略 / 错误日志定位输入问题。
